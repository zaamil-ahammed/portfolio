# Ahammed Shamil — Portfolio Landing Page

> *"Clarity over noise"* • 42RGB Design Unit

A modern, high-performance portfolio landing page built with **React**, **Tailwind CSS**, and **Vite**, featuring a Bento Grid layout, dark obsidian aesthetic, and direct social/contact integration.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```

---

## 🛠️ Customizing Your Details
All personal details, socials, projects, and contact channels are centralized in:
📂 `src/data/portfolioData.js`

- Update your email in `portfolioData.contact.email`
- Add your live project URLs in `portfolioData.projects`
- Adjust social links in `portfolioData.socials`
